Trigonometric Ratios

Cosine Ratio

For angle A, cosine equals adjacent over hypotenuse.

Main Formula

cos(A) = b / c

Variables

  • A = acute angle
  • b = adjacent leg
  • c = hypotenuse

Usage Notes

  • Output is dimensionless.
  • Require c > b > 0.
