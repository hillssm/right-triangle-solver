Trigonometric Ratios

Tangent Ratio

For angle A, tangent equals opposite over adjacent.

Main Formula

tan(A) = a / b

Variables

  • A = acute angle
  • a = opposite leg
  • b = adjacent leg

Usage Notes

  • Output is dimensionless.
  • Require b > 0.
