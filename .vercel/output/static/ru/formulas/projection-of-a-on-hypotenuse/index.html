Hypotenuse Segment p

Projection of leg a onto hypotenuse c.

Main Formula

p = a^2 / c

Variables

  • a = leg
  • c = hypotenuse
  • p = projection segment

Usage Notes

  • Together with q, satisfies p + q = c.
  • Requires c > 0.
