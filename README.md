# Right Triangle Calculator

A premium, luxury-themed geometry workspace built with Astro and Tailwind CSS.

## Features
- **Instant Solving**: Calculate missing sides and angles as you type.
- **Solution Steps**: View detailed mathematical derivations for every answer.
- **Visual Feedback**: Real-time scaled triangle visualization.
- **Multi-language**: Support for English and Arabic (RTL).
- **SEO Optimized**: Complete metadata, schema, and sitemap integration.

## Development
```sh
npm install
npm run dev
```

## Build
```sh
npm run build
npm run preview
```
