## 4. MAIN MATHEMATICAL FORMULA

Use the following consistent notation throughout the article:

a = first perpendicular leg

b = second perpendicular leg

c = hypotenuse

h = altitude from the right-angle vertex to the hypotenuse

Main formula:

**h = (a × b) / c**

Explain that this formula calculates the perpendicular altitude to the hypotenuse, not the height measured relative to either leg.

For a valid nondegenerate right triangle:

a² + b² = c²

Therefore, when only the two legs are known:

c = √(a² + b²)

And:

h = ab / √(a² + b²)

When all three sides are provided, they must satisfy the Pythagorean theorem, allowing for reasonable measurement rounding.

Do not suggest that any arbitrary three positive side lengths form a right triangle.
